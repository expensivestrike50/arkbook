# ArkBook — Bible Podcast UI

A self-contained HTML/CSS/JavaScript prototype based on the requested Bible devotional podcast dashboard.

## Run in VS Code

1. Open this folder in VS Code.
2. Open `index.html`.
3. Either:
   - double-click `index.html` to open in your browser, or
   - install the VS Code **Live Server** extension and choose **Open with Live Server**.

No build step is required.

## Included
- Dark purple Bible podcast dashboard
- Sidebar navigation
- Daily devotional hero
- Interactive play/pause demo
- Episode cards
- Search filter
- Scripture network / Obsidian-style graph
- Verse of the day
- Prayer corner
- Streak tracker
- Topic networks
- Sticky bottom audio player
- Note/prayer modal
- Responsive layout
